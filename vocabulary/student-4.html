The rule

One word can become a noun, verb, adjective or adverb by adding an ending (suffix) or a beginning (prefix).

employ (verb) → employer, employee, employment (nouns) → unemployed (adjective)

In the exam, look at the gap: what type of word does the sentence need? After a / the you usually need a noun. Before a noun you usually need an adjective.

Common endings

To make a... Add Examples
noun -tion / -sion inform → information, decide → decision
noun -ment develop → development, agree → agreement
noun -ness happy → happiness, kind → kindness
noun -ity possible → possibility, popular → popularity
noun (person) -er / -or / -ist / -ant teach → teacher, act → actor, science → scientist, assist → assistant
adjective -ful / -less help → helpful, helpless
adjective -able / -ible enjoy → enjoyable, sense → sensible
adjective -ous danger → dangerous, fame → famous
adjective -ive create → creative, attract → attractive
adjective -al nation → national, profession → professional
adverb -ly careful → carefully, easy → easily

Negative prefixes

Prefix Examples
un- unhappy, unusual, unemployed
dis- disagree, dishonest, dislike
im- (before m, p) impossible, impatient, immature
in- incorrect, independent, informal
ir- (before r) irregular, irresponsible
il- (before l) illegal, illogical
mis- (= wrongly) misunderstand, misspell
