The rule

Ask yourself: is this real, imaginary now, or imaginary in the past?

The less real it is, the further back the tense goes.

Never use will or would in the if part of the sentence. If it will rain... If it rains...

The four conditionals

Type Use it for if + ... result Example
Zero Facts, always true present present If you heat ice, it melts.
First Real, possible future present will + verb If it rains tomorrow, I'll stay home.
Second Imaginary or unlikely, now or future past would + verb If I won the lottery, I would buy a boat.
Third Imaginary past (it didn't happen) had + past participle would have + past participle If I had left earlier, I would have caught the train.

Useful extras

  • If I were you, I'd... is how we give advice. (were for all persons is correct; was is common in speech.)
  • unless = if not. I won't go unless you come. = I won't go if you don't come.
  • You can start with either part. Use a comma only when if comes first: If it rains, I'll stay home. / I'll stay home if it rains.

Wish

To talk about... Use Example Meaning
Now wish + past I wish I had a car. I don't have a car.
Ability now wish + could I wish I could swim. I can't swim.
The past wish + had + past participle I wish I had studied more. I didn't study enough.

Watch out

  • If it will rain, I stay home. If it rains, I will stay home.
  • If I would have money, I would buy it. If I had money, I would buy it.
  • If I had known, I would come. If I had known, I would have come.
  • I wish I can speak French. I wish I could speak French.
