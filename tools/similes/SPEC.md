# Advanced English: Similes units

Same format and rules as tools/metaphors/SPEC.md (read it: every field, the COPYRIGHT RULE, accuracy, counts and quality rules apply unchanged).
Files: tools/similes/<n>.json (n = 1..6). Build: python3 tools/metaphors.py (it builds both sub-sections; --check to validate).
Outputs: advanced/similes/unit-<n>.html, advanced/similes/homework-<n>.html, practice/bank/as-<n>.js.

Differences for similes:
- "title" is the unit name (e.g. "As ... As: Describing People"); "tagline" a short description.
- "bigidea": 2-3 paragraphs on how this kind of simile works (the frame, why natives use it, tone, how it differs from a metaphor where relevant).
- "hidden": 5-8 everyday comparisons or simile-like phrases students already hear (e.g. <strong>like crazy</strong>, <strong>as soon as possible</strong> is NOT a simile: avoid false examples; use real ones like "it went <strong>like clockwork</strong>").
- "expressions": 8 similes. In "note", flag regional use (British vs North American), outdated ones, and common wrong versions (e.g. "as cold as snow" for as cold as ice).
- Mistakes should include: wrong comparison noun, missing "as" (e.g. "cool as cucumber" is fine informally, but "as cool like a cucumber" is wrong), like vs as confusion, literal translations from the student's language, overusing cliches.
- Exercises: "type" should usually ask for the missing comparison noun ("as stubborn as a ___"); "bend" covers natural variation (dropping the first "as" in casual speech, "about as useful as", adding "a real", "like a bat out of hell" register).
- Keep it adult and respectful; no similes that mock groups of people.
- Do not repeat these expressions already taught in the Metaphors units: a fish out of water, the elephant in the room, a dark horse. Everything else is fine.
- Optional "pic" on each expression: {"img": ["<file in advanced/similes/img>", ...], "label": "a mule"}. One or two pictures of the comparison noun(s), shown at the top of the card with the label. Use Microsoft Fluent Emoji 3D (MIT) or a picture drawn for the site; no photos without a free licence and a credit.
