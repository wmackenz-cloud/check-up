Metaphors

Twelve units for very advanced (C1/C2) students. Each unit is built on one big image (argument is war, understanding is seeing, time is money...), so students learn how metaphors work as a system, not just a list. Each has expression cards, examples from literature, poetry and music, seven interactive exercises with an answer key, and a separate homework drill. Open Metaphors on its own page.

Each has expression cards, examples from literature, poetry and music, seven interactive exercises with an answer key, and a separate homework drill. Open Similes on its own page.
