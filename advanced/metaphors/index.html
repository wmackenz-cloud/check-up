Metaphors

Twelve units for very advanced (C1/C2) students. Each unit is built on one big image (argument is war, understanding is seeing, time is money...), so students learn how metaphors work as a system, not just a list. Each has expression cards, examples from literature, poetry and music, seven interactive exercises with an answer key, and a separate homework drill.

This page is for you. Send students the unit link for the lesson, and the homework link after it.
